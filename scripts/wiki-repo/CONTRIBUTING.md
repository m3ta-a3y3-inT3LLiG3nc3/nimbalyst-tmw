# Contributing

This repository is generated. The source lives in the [Nimbalyst monorepo](https://github.com/nimbalyst/nimbalyst), and each release is staged here from it (the `SOURCE` file names the commit).

- **Issues** are welcome here.
- **Pull requests** are welcome here too. We apply accepted changes to the source in the monorepo, credit you, and the next release brings them back. The pull request itself is closed rather than merged.

Where things come from:

| Here | In the monorepo |
| --- | --- |
| `skills/setup`, `skills/update` | `packages/extensions/knowledge/skills-source` (generated by `scripts/build-wiki-plugin.mjs`) |
| other `skills/`, `hooks/`, manifests, `README.md` | `plugins/nimbalyst-wiki` |
| `scripts/nim-local-mcp.mjs` | `packages/cli/src/mcp` (bundled) |
| `scripts/session-inputs.mjs` | `packages/extensions/knowledge/src/sessionInputs` (bundled) |
| `web/` | `packages/wiki-web` (built) |
| `FORMAT.md` | `packages/local-wiki/FORMAT.md` |
